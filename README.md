## 📝 אודות הפרויקט
אפליקציית Frontend מודרנית המציגה קטלוג מוצרים דינמי. המערכת נבנתה בדגש על חוויית משתמש חלקה, עיצוב רספונסיבי מלא וביצועים מהירים.

## ✨ תכונות עיקריות
* **קטלוג מוצרים:** תצוגה ויזואלית של מגוון דונאטס עם מחירים ותיאורים.
* **רספונסיביות:** התאמה מלאה לכל סוגי המכשירים (מובייל, טאבלט ומחשב).
* **ממשק משתמש (UI):** עיצוב נקי ומזמין המותאם למותג.

## 🛠 טכנולוגיות
* **JS / React / Vue**
* **CSS3 & HTML5**
* **Netlify Hosting**
